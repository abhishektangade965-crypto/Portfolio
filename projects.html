Delivoos — Food Delivery Enterprise

Spring Boot · Kafka · Redis · Microservices · API Gateway

Designed and developed an event-driven food delivery coordination backend system resolving high transaction lock bottlenecks.

What I Built

  • Configured Saga transactional patterns via Apache Kafka to orchestrate orders asynchronously across 8 microservices.
  • Built a central API Gateway for load balancing routing, request logging filters, and mapping path translations.
  • Integrated Redis caching for catalog lookups, yielding a 45% reduction in API server response latencies.

Saga Orchestration Architecture Flow

sequenceDiagram
  autonumber
  actor Client as Client App
  participant GW as API Gateway
  participant OS as Order Service
  participant KF as Apache Kafka
  participant BS as Billing Service
  participant DS as Delivery Service
  participant RD as Redis Cache

  Client->>GW: POST /api/v1/orders (Place Order)
  GW->>OS: Route Request
  OS->>RD: Check Inventory Cache
  RD-->>OS: Cache Hit (Fast Lookup)
  OS->>KF: Publish "OrderCreated" Event
  KF->>BS: Process Payment Transaction
  BS-->>KF: Payment Approved Event
  KF->>DS: Dispatch Courier Assignment
  DS-->>Client: Real-Time Order Confirmed Status

Performance Outcome

A highly scalable, asynchronous order fulfillment platform capable of handling concurrent transactions without database locks.

SmartBank — Enterprise Banking

Spring Boot · Spring Security 6 · JWT · MySQL

Built a digital banking system with role-based security configurations and strict transactional ledger controls.

What I Built

  • Developed 30+ secure REST APIs executing transactional bookkeeping steps with ACID validation.
  • Configured endpoint isolation using Spring Security 6 stateless filter chains and JWT verification.
  • Simulated and benchmarked 10K+ transactions to verify ledger consistency under concurrent transfer threads.

Stateless Security & Ledger Transaction Flow

sequenceDiagram
  autonumber
  actor User as Bank Client
  participant SEC as Spring Security 6
  participant JWT as JWT Filter
  participant API as Transfer REST API
  participant DB as MySQL Ledger (ACID)

  User->>SEC: POST /api/v1/auth/login
  SEC-->>User: Return Signed JWT Bearer Token
  User->>SEC: POST /api/v1/transfer (Bearer Token + Payload)
  SEC->>JWT: Validate Token Signature & Expiry
  JWT-->>SEC: Token Authenticated (ROLE_USER)
  SEC->>API: Execute Balance Transfer
  API->>DB: Begin ACID Transaction (Lock Rows)
  DB-->>API: Debit/Credit Ledger Updated
  API-->>User: 200 OK Transfer Receipt

Performance Outcome

A highly secure digital ledger backend demonstrating 45% faster response times via optimized query index paths.
